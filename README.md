# Lúmina — Modelo de Clínicas Odontológicas 1

Modelo institucional responsivo criado para o portfólio da **Guará Agency**.

Site público: https://guaraagency-julio.github.io/modelo-clinicas-1/

## Referência de arquitetura de conteúdo

Inspirado na organização visual e nas seções públicas de https://www.dentalarteclinicas.com.br/: cabeçalho azul-petróleo, hero fotográfico, bloco de agendamento rápido, institucional, tratamentos, busca de unidades, artigos, formulário e rodapé.

Implementação autoral independente, sem incorporar o código-fonte nem os arquivos de marca e as imagens proprietárias da Dental Arte. A marca **Lúmina**, as unidades, os textos e as informações comerciais são fictícios e devem ser substituídos antes de qualquer uso comercial.

## Funcionalidades

- Design responsivo; navegação mobile; submenu de tratamentos.
- Catálogo com **19 tratamentos** ilustrativos; filtros por especialidade; modais de explicação.
- Busca de unidades **fictícias** por estado/cidade como demonstração.
- Blog demonstrativo com artigos explicativos originais.
- Pré-agendamento que **gera mensagem local para copiar**. Sem banco de dados, WhatsApp real ou transmissão de dados.
- Open Graph, acessibilidade básica, metadados e GitHub Actions para Pages.

## Arquivos

`index.html`, `styles.css`, `app.js`, `favicon.svg` e `.github/workflows/pages.yml`.

## Para personalizar e vender

Substitua identidade visual, fotos, dados da clínica, profissionais e responsáveis técnicos, endereços e horários reais, especialidades efetivamente oferecidas, política de privacidade e textos clínicos revisados pelo cliente. Configure o número de WhatsApp próprio ou sistema de agendamento real, inclusive consentimento e tratamento de dados conforme LGPD.

As fotografias desta demonstração são carregadas de endereços públicos do Unsplash. Ao entregar um projeto, prefira imagens próprias ou ativos com licenciamento documentado.

## Publicação

O workflow publica os arquivos da branch `main` em GitHub Pages. Verifique em Settings → Pages se Build and deployment está definido para **GitHub Actions**.
